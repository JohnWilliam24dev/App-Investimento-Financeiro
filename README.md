# App Investimento Financeiro

Side project para treino de **Flutter** (frontend) com possível backend em **NestJS + TypeScript**.

## Objetivo

Aplicativo de controle e simulação de investimentos pessoais: cadastro de ativos, acompanhamento de carteira e projeções simples de rentabilidade.

## Stack planejada

- **Frontend:** Flutter (Dart)
- **Backend:** NestJS + TypeScript (a definir se será necessário desde o início ou só quando houver persistência/autenticação)
- **Banco de dados:** a definir (PostgreSQL é o candidato natural dado o uso de SQL/PLSQL)

## Fluxo de trabalho

- Toda alteração é feita na branch `develop`.
- A `main` só recebe merge via Pull Request, depois de revisão e teste local.

## Status

🚧 Projeto em fase inicial de estruturação.
